# Batch Data Ingestion Pipeline into Snowflake: Beginners Project

### This project will teach you how to build a batch ingestion pipeline, where new data is automatically ingested from AWS S3 into Snowflake without Snowpipe. The goal is to automatically load new CSV files from AWS S3 into a Snowflake table using the COPY INTO command. We need to setup S3 and Snowflake integration.
